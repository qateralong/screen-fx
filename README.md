# ScreenFX

Fabric mod: the server triggers screen effects on players: overlays, eyelids, frost, color filters, distortions, camera motion, resource-pack shaders and images, with server presets.

## Features

- Overlays, eyelids, frost and vignette.
- Color filters and distortions (sepia, VHS, glitch, fisheye, thermal and many more post shaders).
- Camera motion effects.
- Resource-pack shaders and images.
- Server-defined presets.

## Commands

`/screenfx` triggers effects; `/screenfx list` shows them, `/screenfx clear` removes them, `/screenfx reload` reloads presets.

## Compatibility

Minecraft 1.21.1, Fabric Loader and Fabric API. Install on the server (and on clients for the effects).

## Build

```bash
./gradlew build
```

The jar appears in `build/libs/`.
